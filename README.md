# XunZi-PD

XunZi-PD is a read-only research explorer for inspecting a completed, frozen Parkinson's disease gene-prioritization analysis.

## Public website

The GitHub Pages site opens the Beginner experience by default. It supports candidate discovery, gene evidence review, protein-network context, pathway membership, PD genetics context, and a local-only research workspace.

## Scientific boundary

This website presents research-priority and evidence-context information only. It is not a clinical diagnostic tool, does not establish disease causality, and does not identify or recommend a validated therapeutic target.

The published bundle:

- does not retrain a model or rerun the analysis;
- does not expose raw FASTQ or BAM data;
- does not change the frozen STAT-DE-v1 or STRING-RWR-v1 rankings;
- stores shortlist, notes, and reading progress only in the visitor's browser.
